# BookMeter · 全网书评权威聚合指南

> 基于 GitHub 优质开源书评聚合系统架构（参考 NeoDB、BookWyrm 等项目设计模式），聚合 **豆瓣读书 (10分制)**、**Goodreads (5星制)**、**Amazon 购书验证评价** 与 **Google Books** 多源真实口碑，彻底打破单一平台水军刷分、粉圈控评与机翻翻车误导，让读者一眼看清哪些书真正封神、哪些是避坑踩雷。

---

## 🌟 核心解决的痛点

1. **单一平台评分虚高与刷分偏见**：
   - 某些畅销鸡汤书或商业营销书在国内某些渠道营销推广下评分虚高，但海外或专业读者差评如潮；
2. **机翻劣质译本“毁神作”现象**：
   - 很多世界级名著原著在 Goodreads 高达 4.0+ 星，但国内部分出版社使用机械翻译、语病连篇，在豆瓣遭遇 4.1 分滑铁卢（如《机械心》翻车译本）。本系统独创**跨平台分歧指数（Discrepancy Index）**，第一时间向读者发出译本避坑预警！
3. **直观看到“为什么好”与“为什么不好”**：
   - 读者不需要去翻几千条评论，系统直接提炼**核心好评亮点 (Pros)**、**差评槽点与劝退提示 (Cons)** 与**读者高频标签云**。

---

## 🤖 DeepSeek AI 深度对冲与避坑雷达 (新特性)

系统已原生深度集成 **DeepSeek-V3/R1 大模型**（通过官方 API 驱动）：
1. **一针见血定性（Sharp Verdict）**：破除商业营销与粉圈水军滤镜，给出真正客观犀利的定性评价；
2. **深度价值亮点 vs 致命硬伤与槽点**：提炼全网真实好评与差评；
3. **适合受众 vs 坚决劝退受众**：明确指出哪些人适合读、哪些人千万不要买；
4. **译本与版本专业指南**：对于外文翻译书籍，分析各版本中文翻译优劣，警惕机翻踩雷；
5. **实时智能问答顾问**：读者可在图书详情弹窗中直接就阅读门槛、版本选择向 DeepSeek 提问。

## 🧮 权威算法模型

### 1. 跨平台多维度归一化 (Scale Normalization)
各平台评分尺度不一（豆瓣为 10 分制，Goodreads、Amazon、Google Books 为 5 星制）。系统统一将 5 星制转换为标准 10 分制：
$$R_{10} = R_5 \times 2$$

### 2. 贝叶斯加权主评分 (Bayesian Weighted Rating - IMDb/Metacritic 算法)
避免只有几个 5 星评分的冷门书压过几十万人参评的真经典：
$$WR = \frac{v}{v + m} R + \frac{m}{v + m} C$$
- $v$：各平台累计评价总人数
- $m$：置信度最小评价阈值（默认 500 票）
- $R$：该书在各平台的加权平均分（10 分制）
- $C$：全书库基准平均分（约 7.8 分）

### 3. 跨平台文化/译本分歧指数 (Discrepancy Index)
$$\Delta = | R_{\text{douban}} - 2 \times R_{\text{goodreads}} |$$
- 当 $\Delta \ge 1.0$ 时，系统自动触发**分歧警示**，深入剖析文化差异或劣质译本原因。

### 4. 口碑评级体系 (Verdict Classification)
- 👑 **殿堂神作 (Masterpiece)**：综合分 $\ge 9.0$ 且负评率 $< 8\%$，全网零死角公认经典（如《活着》《三体全集》《深入理解计算机系统 CS:APP》）。
- 📚 **经典必读 (Recommended)**：综合分 $\ge 8.2$，多平台口碑过硬（如《百年孤独》《人类简史》《代码整洁之道》）。
- ⚖️ **两极分化 / 争议 (Controversial)**：分歧指数大或差评率较高，口碑剧烈撕裂（如《富爸爸穷爸爸》《秘密》）。
- ⚠️ **避坑预警 (Warning / Caution)**：综合分 $< 6.0$ 或差评率 $\ge 40\%$，营销炒作快餐书或劣质机翻翻车（如《元宇宙狂潮》《机械心（某翻车译本）》）。

## 🚀 核心功能与页面模块

- 🧭 **全部书库全景探索**：支持按分类（文学小说、科幻世界、计算机技术、商业经管、历史社科、哲学心理）快速切换，支持多维度即时排序。
- 🔍 **全网实时动态拉取与搜索**：本地未收录书籍自动对接 Google Books API 与开放接口实时计算预估分值。
- ⚖️ **好书 vs 避坑 横向全景对决 (Comparison View)**：左右双栏直观对比“口碑天花板”与“踩雷重灾区”。
- 📖 **深度对冲报告弹窗 (Deep-Dive Modal)**：
  - 四大平台原站星级与折算分直观对比，一键跳转原站核实
  - 为什么说它好（读者好评提炼） vs 为什么有人打差评（劝退槽点）
  - 豆瓣精选长评、Goodreads 认证热评、Amazon 真实买家反馈多源展示
- ⏱️ **自动化抓取与定时排程 (Schedule Pipeline)**：
  - 针对每日自动抓取与反爬对冲的排程管理
  - 支持在 UI 中一键手动触发全网爬虫重算与增量更新

## 🛠️ 技术架构

- **前端 (Frontend)**：React 18 + Vite + Tailwind CSS + Lucide React 图标库 + 现代化响应式流式布局
- **后端 (Backend)**：Node.js + Express + Axios + Cheerio / Google Books REST API
- **数据与对冲层**：贝叶斯多平台对冲算法 + 正负面好差评特征工程

## 🏃 快速启动指南

### 1. 启动全栈服务（前后端集成模式）
```bash
npm start
```
> 服务将在 **http://localhost:5000** 启动，自动提供 API 与编译好的前端页面。

### 2. 开发模式（支持前端热更新与代理）
```bash
# 启动 Express 后端 API (端口 5000)
npm run server

# 另起终端启动 Vite 前端开发服务器 (端口 3000，已自动代理 /api 到 5000)
npm run client

# 或使用一键并发启动:
npm run dev
```
